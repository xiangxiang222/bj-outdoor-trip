# 订单、同城局、行程与消息修复

本轮在已有工作区修改基础上检查并补齐，小程序与手机 H5 同步处理。

## 行为约定

- 订单详情使用状态区、活动安排、参与人、费用与订单信息分区。待付款明确显示剩余待付金额；同城活动隐藏车辆座位，结束或取消后只显示适用操作。评价表单打开后不保留空的底部操作栏。
- 同城局采用紧凑的类型封面、活动状态与时间地点布局。报名、待付款、候补、待确认、审核、开始、结束及取消分别显示对应提示；结束后不再显示到场、余位和候补招募提示。
- 掼蛋、跑步、电影与招募均可发布真实微信群二维码和群说明，支持预览、替换、移除。未上传时不根据文字生成二维码。群信息只向发起人和已确认且完成费用支付的参加者展示。
- 同城订单在活动开始前可取消，包括活动当天尚未开场时；已付费用按原付款人原路全额退回。发起人可撤回审核中、审核未通过及尚未开场的已通过活动，已开始或结束的活动不可取消。
- 消息支持全部、未读、已读筛选、全量计数、分页和全部标为已读；标记结果不会被旧请求覆盖。
- 行程顶部三个数字是待出发、待付款、已结束的常用状态入口。当前入口用底色、边框和勾选强调，完整状态仍可从标签与筛选面板选择。筛选即时生效，叉号与遮罩关闭均保留有效条件；倒置日期显示错误并保留上次有效范围。
- 行程默认显示全部报名；同城局或户外团报名成功后，返回行程或“我的”会重新获取列表和计数，旧账号及较早请求不会覆盖新结果。
- 同城局为单次活动，不提供再次报名或线路详情入口。线路团结束后仅提供“查看其他团期”，线路下只展示仍可报名的团期。服务端拒绝已开始或结束团的新报名，同时覆盖候补递补、摄影师转换及志愿领队入口。
- 掼蛋、跑步、电影、招募和山野行程分别使用对应缺图图标；小程序按钮覆盖微信 v2 默认固定宽度，防止筛选栏与底部按钮被挤压。
