说明小程序原生能力、H5 文件选择、本地缓存及拒绝授权的影响。系统弹窗与个人信息单独同意各有边界。

## 一、按操作调用的设备能力

### 相册及文件选择

| 项目 | 说明 |
| --- | --- |
| 触发 | 主动更换头像、上传照片、认证材料、反馈或活动图片等。 |
| 用途与范围 | 通过微信媒体选择或 H5 文件选择读取你选定的文件；不读取整个相册。部分系统选择器不需要开放整个相册权限。 |
| 拒绝影响 | 不能选择对应图片，可继续使用不需要上传的功能。 |

### 相机

| 项目 | 说明 |
| --- | --- |
| 触发 | 在媒体选择器中主动选择拍摄。 |

| 拒绝影响 | 不能现场拍摄，可选择已有图片或使用无上传需求的功能。 |

### 保存图片到相册

| 项目 | 说明 |

| 拒绝影响 | 无法直接保存，可按页面提示预览或使用系统提供的保存方式。 |

### 剪贴板

### 微信手机号授权与订阅消息

| 项目 | 说明 |

| 拒绝影响 | 可选择其他登录方式；不订阅不影响报名，可在订单和站内消息查看信息。 |

| 触发 | 点击集合点地图。 |
| 用途与范围 | 向地图传入集合点坐标；当前不采集设备实时或后台位置。不应为了显示固定集合点而要求提供持续定位权限。 |
| 拒绝影响 | 可直接查看集合点文字；后续在第三方地图选择导航时，由该服务自行请求其所需授权。 |

## 二、本地存储及网络请求

小程序和 H5 使用本地存储保存登录令牌、用户资料缓存、随机访客标识、首页缓存、字体、主题和语言等偏好，以维持登录、呈现页面及保留你的设置。登录令牌属于安全凭证，请勿公开；退出登录会清除相应登录信息，但不当然清空所有访客标识、偏好和服务端记录。

你可通过微信、浏览器或系统提供的清理缓存方式管理本地数据；清理后可能需要重新登录、重新设置偏好，随机访客标识也可能重新生成。网络请求是获取线路、订单及上传资料所需的通信方式，不等同于取得任意设备资料的授权。

H5 的浏览器及所嵌入第三方页面可能采用其自身存储或 Cookie 机制；实际启用的外部页面须按其规则说明，并与本产品第三方清单核对。

## 三、管理授权

可在微信的小程序设置、隐私与授权管理，或手机系统的微信、浏览器权限设置中查看和调整相应授权，实际入口随微信、系统和浏览器版本变化。撤回设备权限一般只影响以后对相应能力的使用，不自动删除已经上传到服务端的信息；删除历史信息可通过权利请求渠道提出。

系统权限弹窗不当然构成敏感个人信息、向其他独立处理者提供、公开披露或个人信息出境所需的全部告知和单独同意。对应功能仍应满足相关法律要求。
