说明敏感信息的必要性、可能影响与单独同意边界。本页是告知文件，打开或阅读不等于授权。

## 一、适用原则与确认方式

身份证等特定身份、金融账户、健康信息、不满十四周岁未成年人个人信息，以及可能危及人身或财产安全的具体行程信息，须依具体情况按敏感个人信息保护要求处理。我们应具有特定目的和充分必要性，采取严格保护措施，并说明对个人权益的影响。

依法基于同意处理敏感个人信息时，应在对应功能取得单独同意，不能预先勾选、捆绑全部功能，或以用户协议、健康风险确认、系统权限授权替代。你可仅授权使用所选择功能必要的处理事项，并依法撤回同意。当前本页不包含独立的授权按钮，也不作为已经取得授权的凭证。

## 二、具体场景、必要性与影响

### 实名核验

| 项目 | 说明 |
| --- | --- |
| 处理内容 | 姓名、完整身份证号、核验结果，及根据证件解析的出生日期、性别和籍贯。 |
| 特定目的及必要性 | 核对特定服务中的身份及资格，限于具有真实核验需求的场景；不应作为公开浏览的必要条件。不采集人脸。 |
| 接收方与方式 | 服务端保存并在真实核验时向已公示的阿里云认证提供方提交；须在传输前确认接收方及相应处理依据。 |
| 可能影响及拒绝后果 | 泄露可能导致身份冒用和关联识别；拒绝将无法完成需真实核验的相应功能，不影响无关服务。 |

### 户外报名与安全联络

| 项目 | 说明 |
| --- | --- |
| 处理内容 | 报名所需身份证号、必要的健康适合确认、具体行程、紧急联系人及安全联络信息。 |
| 特定目的及必要性 | 按实际活动核对资格、人员和紧急联系，不能以保险名义收集尚无真实承保用途的非必要资料。健康确认不要求详细病史。 |
| 接收方与方式 | 订单服务保存，履约人员按权限访问必要内容；公开接龙及向独立组织者提供应分别履行告知与必要授权。 |
| 可能影响及拒绝后果 | 可能暴露身份、出行时间及身体状况；拒绝确为履约及安全所必需信息可能无法报名对应户外活动，同城轻活动采用较少字段。 |

### 校园及校友证明

| 项目 | 说明 |
| --- | --- |
| 处理内容 | 学号、证明图片中可识别个人身份的资料；图片可能包含照片、证件编号等。 |
| 特定目的及必要性 | 审核学生或校友资格与优惠；应允许遮挡无关证件号、住址等字段，并将原件与审核结论分别设定必要期限。 |
| 接收方与方式 | 人工审核；上传图片还可能经过微信内容安全接口，不等同于外部学籍核验。 |
| 可能影响及拒绝后果 | 资料泄露可能造成身份关联和冒用；不提交可不申请专属资格，仍可使用无身份限制的服务。 |

### 支付、钱包与提现

| 项目 | 说明 |
| --- | --- |
| 处理内容 | 交易及支付相关标识、金额、账本、支付状态、微信零钱转账信息、钱包支付密码哈希。 |
| 特定目的及必要性 | 支付、退款、结算及提现需要；不收取微信支付密码，当前不新增银行卡绑定。 |
| 接收方与方式 | 财付通支付科技有限公司通过支付或转账接口处理必要交易信息，详见共享清单。 |
| 可能影响及拒绝后果 | 泄露或冒用可能造成财产风险；不提供必要支付信息时无法完成相应支付或提现，仍可浏览。 |

### 未成年人资料、公开披露与跨境

| 项目 | 说明 |
| --- | --- |
| 处理内容 | 不满十四周岁未成年人资料；可识别个人的行程或其他公开内容；自由文本中可能涉及的个人信息。 |
| 特定目的及必要性 | 儿童参加、面向明确受众的分享或外部模型辅助应分别论证，不以一次总授权包揽。 |
| 接收方与方式 | 儿童应取得监护人同意并适用专门规则；公开披露应明确受众；境外传输应公示实际境外接收方及行使权利方式。 |
| 可能影响及拒绝后果 | 可能产生不当联系、人身安全及跨境维权风险；在必要保障及授权未具备前不应开启对应处理，不影响无关功能。 |
