按功能列明信息种类、用途、处理方式、触发时机、必要性和保存规则；不将可选功能的信息列为浏览必填。

## 一、按场景列明的收集事项

本清单对应当前功能。除法律另有规定外，只有你使用相关功能时才处理对应资料；同一信息用于新目的仍须另行判断依据。

### 1. 手机注册、密码或短信登录

| 项目 | 说明 |
| --- | --- |
| 信息种类 | 手机号、密码哈希、验证码及校验记录；自填昵称。 |
| 目的与方式 | 由你主动提交，服务端验证并保存账号及验证记录，用于身份校验、登录和防止验证码滥用。 |
| 触发与必要性 | 选择手机登录或注册时；手机号及相应验证信息为该方式所需。当前手机号密码注册页面要求填写昵称，短信登录新建账号可生成默认昵称；昵称不必是真实姓名。拒绝注册可继续浏览公开内容。 |
| 保存规则 | 账号身份信息保留至注销或处理目的消除；验证有效期不等于验证记录的删除期限，相关日志须按安全必要性设置清理。 |

### 2. 微信登录及手机号授权

| 项目 | 说明 |
| --- | --- |
| 信息种类 | OpenID、接口提供的 UnionID；你授权的手机号；另行选择提供的昵称和头像。 |
| 目的与方式 | 调用微信服务端接口取得并绑定账号，不读取微信好友、通讯录或聊天记录。 |
| 触发与必要性 | 主动选择微信登录或微信手机号授权；不授权手机号可选择其他可用登录方式。 |
| 保存规则 | 绑定关系保留至解绑、注销或目的消除，法定必要记录另行处理。 |

### 3. 个人资料与实名核验

| 项目 | 说明 |
| --- | --- |
| 信息种类 | 昵称、头像、性别、生日、籍贯、公司名称；实名核验的姓名、身份证号和核验结果。身份证号可解析出生日期、性别、籍贯。 |
| 目的与方式 | 用户输入或上传；服务端保存，并在启用真实核验时向阿里云认证接口传输姓名及证件号。 |
| 触发与必要性 | 资料完善或主动实名核验时；资料展示字段可选，实名信息限有明确核验需要的功能，不作为公开浏览条件。不采集人脸。 |
| 保存规则 | 按账号、核验及履约目的所必需期限保存；证件原文应单独判断最短必要期限。 |

### 4. 户外行程报名及签到

| 项目 | 说明 |
| --- | --- |
| 信息种类 | 姓名、手机号、身份证号及解析信息；紧急联系人姓名和手机号；健康适合、风险告知确认及时间；行程、座位、报名、签到和费用记录。 |
| 目的与方式 | 你填写或确认后存入订单；用于参加条件、安全联络、人员核对、行程执行、计价及售后。 |
| 触发与必要性 | 报名户外行程时按实际必要性提交；拒绝履约和安全所必需信息可能无法完成该行程报名，仍可浏览其他内容。 |
| 保存规则 | 交易记录依适用法定期限保存；身份证原文、紧急联系人和健康确认分别依实际目的最短必要期限处理，不以交易期限一概保留。 |

### 7. 校园、校友、团体、领队和线路收录申请

| 项目 | 说明 |

| 保存规则 | 证明原件以审核、复核必要期限为限，非必要字段应遮挡；审核结论与原件分别判断保留。线路联系信息按审核、沟通及奖励核算的必要期限处理。 |

### 8. 支付、退款、会员、钱包及奖励

| 保存规则 | 适用交易记录依法保存不少于交易完成后三年；账务资料按相关法律期限处理，不一概适用于全部账号资料。 |

## 二、未使用的能力与范围说明

当前没有主动获取用户实时精准位置、持续轨迹、通讯录、通话记录、短信内容、录音、人脸或指纹的实现。地图展示的为集合点坐标，天气查询使用目的地区域固定坐标，不是用户所在位置。未来增加处理活动时须重新核对并更新告知。

SDK 或平台自身如何处理设备信息，应查看其独立规则；我们不能把平台的所有处理范围等同于本产品自身收集范围。
