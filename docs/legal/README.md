# 同行者众协议审阅文件

> 从 server/src/services/legal.js 生成；请勿直接修改。版本 2026-11-01，更新日期 2026-11-01，审阅版，尚未正式生效。

以下文件与两端页面使用同一文本源。修改权威文本后运行 `npm run legal:export` 重新生成。正式发布条件、尚需补充的信息及实现限制见 [发布说明](../LEGAL_RELEASE.md)。

- [同行者众隐私政策](./privacy.md)：说明个人信息的处理目的、范围、保存、对外提供及你的权利。请重点阅读敏感信息、公开展示和第三方服务部分。
- [同行者众用户服务协议](./terms.md)：约定账号、活动报名、价格支付、退改、内容发布及争议处理。请重点阅读费用、退改、安全风险与责任承担条款。
- [个人信息收集清单](./collection.md)：按功能列明信息种类、用途、处理方式、触发时机、必要性和保存规则；不将可选功能的信息列为浏览必填。
- [第三方信息共享清单](./sharing.md)：区分微信原生能力、服务端接口、委托处理和外部页面。仅列明对应功能实际涉及的传输，不把使用服务等同于同意全部共享。
- [设备权限与本地存储说明](./permissions.md)：说明小程序原生能力、H5 文件选择、本地缓存及拒绝授权的影响。系统弹窗与个人信息单独同意各有边界。
- [敏感个人信息处理告知](./sensitive.md)：说明敏感信息的必要性、可能影响与单独同意边界。本页是告知文件，打开或阅读不等于授权。
- [账号注销与个人信息权利说明](./cancellation.md)：说明注销前的结算事项、实际删除范围、历史数据处理和可用的个人信息权利渠道。注销不是退出登录。
