# 首页设计检查记录

适用页面：微信小程序首页、网页版首页 `/m`。

## 品牌表达

两端主视觉统一为：

- 眉题：离城市近一点 · 离自然更近一点
- 主标题：在山野，遇见爱
- 副文案：和同频的人，一起出发。

这组表达围绕自然、相遇和同行展开，适用于平日、周末和假期。首页常驻文案不再将出行限定在周末；“本周末”“下周末”保留为用户主动选择的日期快捷项。

## 筛选入口滚动优化

精选线路、高校同行、企业团建、目的地灵感及搜索入口保留原有筛选语义，统一在筛选内容渲染后定位。小程序按滚动距离使用 400–900ms 的缓启停曲线，由 JavaScript 逐步推进，每次 `pageScrollTo` 的 `duration` 均为 0，且等待当前调用完成后才安排下一步；停靠位置避开状态栏和微信胶囊。网页按距离使用 450–850ms 的缓启停动画，仅滚动当前实际承载页面的容器，停在筛选区标题上方 16px。标题已经处于阅读位置时，不强制重新贴顶。

小程序触摸打断只同步作废任务、清理计时器，不再异步查询位置或补写旧位置。重复筛选会在当前瞬时调用完成后重新测量；延迟的渲染、测量及滚动回调均检查任务版本与首页是否仍在前台。首页各跳转、底部 Tab 和优惠券弹窗入口先停止后续滚动，等待唯一在途调用完成后再导航，避免留下跨页运行的长原生动画。页面隐藏或卸载时同时清理任务与待执行导航。网页支持手势、鼠标、键盘中断及系统减少动态效果偏好。异步结果加载时继续以标题为目标，避免加载态页面较短导致停靠偏差。

小程序首页、滚动、日期及线路目录相关 82 项回归通过，覆盖延迟位置查询、延迟桥接回调、触摸中断、重复筛选、页面隐藏与卸载、实际 Tab 与优惠券入口的跳转等待及失败退出；语法与包体检查通过。网页首页和滚动相关 18 项测试、生产构建此前已通过。微信桥接无法撤回已经发出的单次瞬时调用，实际手势中断与切页手感仍需微信真机验收。

网页浏览器验证覆盖 390px 的内容滚动容器和 1440px 的窗口滚动，以及手势中断、减少动态效果、连续筛选和切页取消。390px 的精选线路与目的地入口分别产生 37 / 35 个移动中间帧，首步均为 2px，最终标题距顶部约 16px；加载态停靠偏差已修正。

## 灵感卡片与筛选条件公示

“走出日常，自然会有答案”是区块标题，三张卡片才是筛选入口。此前卡片分别用“长城 / 山 / 海”进行关键词包含匹配，列表没有在附近显示关键词，且“海”可能误匹配“海淀”。现已改用服务端支持的精确线路分类：长城卡为“长城”、山野卡为“登山”、海边卡为“海滨”，不再以单字代替主题分类。

两端线路列表在天数和玩法选项之前显示当前主题、关键词、天数、玩法。每项条件可单独移除，也可一键清空；移除主题或关键词保留其余条件，清空后显示“全部线路”，页顶搜索框同步更新。空结果仍能查看和清除条件。热门词继续使用关键词搜索，新的灵感选择会重置旧的关键词、天数和玩法，保留用户已选的团期日期。

本轮小程序首页、日期、线路目录相关 66 项测试通过；网页首页、目录、滚动和翻译相关 28 项测试、生产构建通过。接口回归 10 项通过，包含海滨与海淀排除及分类与其他条件组合验证。
