# 首页设计检查记录

适用页面：微信小程序首页、网页版首页 `/m`。

当前筛选方案及本轮验证见文末“统一出游偏好与后台同步”，完整规则见[首页筛选设计复核](./home-filter-design-decision.md)。以下各轮记录保留当时的结果；旧版主题、玩法分组及清空规则已由当前方案替换。

## 品牌表达

两端主视觉统一为：

- 眉题：离城市近一点 · 离自然更近一点
- 主标题：在山野，遇见爱
- 副文案：和同频的人，一起出发。

这组表达围绕自然、相遇和同行展开，适用于平日、周末和假期。首页常驻文案不再将出行限定在周末；“本周末”“下周末”保留为用户主动选择的日期快捷项。

按最新反馈，撤去首页独立白色品牌栏，品牌图标和文字叠放在风景图中，图片上沿对齐页面上沿。小程序照片延伸到状态栏区域，品牌内容仍按状态栏、微信胶囊尺寸避让；状态栏使用浅色前景，文字模式恢复适合其背景的配色。搜索、日期和线路浏览行为保持一致。

本轮小程序完成 17 组兼容布局检查（含 47px / 59px 状态栏、大字、英文和文字模式），微信模板与样式编译、包体检查及 50 项相关测试通过。网页完成 20 组多尺寸与显示模式检查，头图顶边均为 0，品牌随头图滚走；首页行为和外观相关 10 项测试、生产构建通过。小程序预览来自实际 WXML / WXSS 的浏览器兼容渲染，仍需微信真机验收。

## 筛选入口滚动优化

精选线路、高校同行、企业团建、目的地灵感及搜索入口保留原有筛选语义，统一在筛选内容渲染后定位。小程序按滚动距离使用 400–900ms 的缓启停曲线，由 JavaScript 逐步推进，每次 `pageScrollTo` 的 `duration` 均为 0，且等待当前调用完成后才安排下一步；停靠位置避开状态栏和微信胶囊。网页按距离使用 450–850ms 的缓启停动画，仅滚动当前实际承载页面的容器，停在筛选区标题上方 16px。标题已经处于阅读位置时，不强制重新贴顶。

小程序触摸打断只同步作废任务、清理计时器，不再异步查询位置或补写旧位置。重复筛选会在当前瞬时调用完成后重新测量；延迟的渲染、测量及滚动回调均检查任务版本与首页是否仍在前台。首页各跳转、底部 Tab 和优惠券弹窗入口先停止后续滚动，等待唯一在途调用完成后再导航，避免留下跨页运行的长原生动画。页面隐藏或卸载时同时清理任务与待执行导航。网页支持手势、鼠标、键盘中断及系统减少动态效果偏好。异步结果加载时继续以标题为目标，避免加载态页面较短导致停靠偏差。

小程序首页、滚动、日期及线路目录相关 82 项回归通过，覆盖延迟位置查询、延迟桥接回调、触摸中断、重复筛选、页面隐藏与卸载、实际 Tab 与优惠券入口的跳转等待及失败退出；语法与包体检查通过。网页首页和滚动相关 18 项测试、生产构建此前已通过。微信桥接无法撤回已经发出的单次瞬时调用，实际手势中断与切页手感仍需微信真机验收。

网页浏览器验证覆盖 390px 的内容滚动容器和 1440px 的窗口滚动，以及手势中断、减少动态效果、连续筛选和切页取消。390px 的精选线路与目的地入口分别产生 37 / 35 个移动中间帧，首步均为 2px，最终标题距顶部约 16px；加载态停靠偏差已修正。

## 灵感卡片与筛选条件公示

“走出日常，自然会有答案”是区块标题，三张卡片才是筛选入口。此前卡片分别用“长城 / 山 / 海”进行关键词包含匹配，列表没有在附近显示关键词，且“海”可能误匹配“海淀”。现已改用服务端支持的精确线路分类：长城卡为“长城”、山野卡为“登山”、海边卡为“海滨”，不再以单字代替主题分类。

两端线路列表在天数和玩法选项之前显示当前主题、关键词、天数、玩法。每项条件可单独移除，也可一键清空；移除主题或关键词保留其余条件，清空后显示“全部线路”，页顶搜索框同步更新。空结果仍能查看和清除条件。热门词继续使用关键词搜索，新的灵感选择会重置旧的关键词、天数和玩法，保留用户已选的团期日期。

本轮小程序首页、日期、线路目录相关 66 项测试通过；网页首页、目录、滚动和翻译相关 28 项测试、生产构建通过。接口回归 10 项通过，包含海滨与海淀排除及分类与其他条件组合验证。

浏览器实测确认三卡请求仅带对应 category，单项移除、全部清空、页顶搜索同步及空结果恢复均生效。320px 暗色最大字号、390px 和 1440px 的条件区无溢出。小程序完成 10 组含长关键词、暗色与大字英文的兼容预览，WXML / WXSS 编译通过；预览不替代微信真机验收。

## 在线路列表自主选择主题

本节保留上一轮实现记录。后续发现主题与玩法存在语义及数据重叠，现已采用文末的单组出游偏好方案。

首页灵感卡选中的主题此前只能通过“已选条件”移除，列表里缺少重新选择入口。小程序与网页现在线路天数之前常驻“全部主题 / 长城 / 登山 / 海滨”一行，与灵感卡、已选条件和请求中的 `category` 使用同一状态。下方切换主题保留关键词、天数与玩法；“全部主题”仅移除主题，清空筛选才重置全部线路条件。下方操作直接更新列表，不触发定位滚动。

小程序独立线路页也复用这组主题按钮，并将传入主题与玩法分别保存在 `category` 和 `tag`，包含相应清空与空结果恢复处理。中文、繁体和英文沿用统一翻译数据。

本轮小程序相关 85 项回归、包体及语法检查通过。实际 WXML 编译后，首页与独立线路页的中英文共 16 种选中状态验证通过；10 组含暗色、大字英文、长关键词的浏览器兼容预览无溢出，全部主题可横向滚动访问。网页相关 23 项测试及生产构建通过；Chrome 实测上方三卡与下方高亮同步，下方四个主题选项保留其他参数，900ms 内垂直滚动变化为 0。390px、320px 暗色大字英文检查通过。小程序兼容预览不替代微信真机验收。

## 统一出游偏好与后台同步

小程序首页、独立线路页和网页版已统一为“单选出游偏好＋天数＋关键词”。默认常用偏好为长城、徒步登山、海边，更多展开其他有覆盖的偏好。三张灵感卡替换同一偏好，保留关键词、天数和团期日期；下方更换偏好不触发页面定位。偏好与天数、关键词相交，数量按当前天数和关键词计算；零结果保留选择，加载失败隐藏未知数字并提供重试。

后台“偏好与标签”可配置名称、排序、常用项、精确分类／完整标签规则及启停；“线路管理”提供偏好筛选、命中标识与编辑实时预览。线路实际分类或任一完整标签命中规则即可归入该偏好，不另存第二份线路归属。发团标签仍用于团期，避免再次混为线路筛选条件。

后台停用偏好时，客户端明确提示重新选择、清空旧结果并刷新配置；不自动放宽为全部线路，已选条件和已知名称保留。动态响应、组件卸载、重试和旧请求覆盖均有回归。服务启动幂等初始化配置，不覆盖已编辑或停用的默认项；旧版分类和玩法参数仍兼容。

本轮服务端 361 项、网页 372 项、小程序相关 102 项测试通过；网页生产构建、小程序语法与包体检查通过。小程序主包源文件估算约 1556 KiB，低于检查器的 2048 KiB 限额，非微信最终编译包体。实际 WXML / WXS 编译与 WXSS 浏览器兼容预览覆盖首页、独立线路页共 20 组，包含 320 / 390px、中文、深色大字英文、更多偏好、当前零结果及数量接口失败。

网页 Chrome 实测确认三卡与下方选择联动、保留基础条件、偏好请求不混入旧分类／玩法、下方筛选垂直滚动为零、停用反馈及数量重试；窄屏和大字模式没有横向溢出。后台隔离数据验证新增、停用、启用、数量与线路编辑预览；未修改真实数据。

尚未合并、部署或发布小程序。微信真机上的手势、切页及日期弹层仍待验收。部署脚本现先启动后端并检查偏好接口，再更新网页；新版小程序同样应在后端就绪后发布。
