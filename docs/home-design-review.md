# 首页设计检查记录

适用页面：微信小程序首页、网页版首页 `/m`。

## 品牌表达

两端主视觉统一为：

- 眉题：离城市近一点 · 离自然更近一点
- 主标题：在山野，遇见爱
- 副文案：和同频的人，一起出发。

这组表达围绕自然、相遇和同行展开，适用于平日、周末和假期。首页常驻文案不再将出行限定在周末；“本周末”“下周末”保留为用户主动选择的日期快捷项。

## 布局与交互调整

| 检查位置 | 完成的调整 | 设计目的 |
| --- | --- | --- |
| 品牌导航 | 保留独立品牌栏；小程序使用微信状态栏和胶囊实测尺寸留出空间 | 品牌信息清晰，避免与系统控件争抢空间 |
| 风景主视觉 | 恢复品牌三句；标题按“在山野，”和“遇见爱”两段自然换行；内容可撑高容器 | 大字号、英文下保留完整文案，避免单字落行和搜索卡遮挡 |
| 图片上的文字 | 增加左侧淡黑渐变，保留照片的层次；移除无关的 BEIYE 字样 | 保证白字可读，保持品牌一致 |
| 主视觉入口 | 改为“发现下一程”，进入团期列表；默认不限日期，保留用户已经选择的日期 | 与全年出游场景一致，尊重已有筛选 |
| 搜索卡 | 标题统一“下一程，想去哪里”；日期默认“出发日期不限”；主按钮统一“寻找我的山野” | 先明确去哪里、何时出发，再进入结果 |
| 快捷入口 | 保留四个轻量入口与不同颜色的线性图标，增进小程序辅助文字的可读性 | 方便识别线路、高校、企业和领队入口 |
| 目的地灵感 | 去除周末限定；减少手机端细小英文装饰；保留三张照片卡片 | 提供直观灵感，控制装饰文字的数量 |
| 列表起点 | 小程序去掉重复的探索标题，直接进入“即将出发 / 精选线路” | 减少层级，让用户更快接触实际内容 |
| 行程卡 | 线路名称独立展示，团型徽标另起一行；统一徽标颜色 | 让名称保持首要阅读位置，避免徽标挤压标题 |
| 深色模式 | 修复网页版品牌栏、页面背景、搜索、行程卡、筛选项与空态按钮的主题颜色 | 避免浅字浅底和多个模块配色割裂 |
| 平板布局 | 网页 760–999px 搜索区采用两列输入与整行按钮 | 避免刚进入桌面布局时搜索输入框过窄 |
| 点击区域 | 主视觉入口、搜索及日期入口保证至少 44px 高；扩大轮播点可点击区域 | 改善手机点击体验 |

## 验证与边界

- 小程序：320 / 390 / 430px，日间、深色、文字模式、中英文最大字号，共 15 组兼容预览。检查页面溢出、文字裁剪、图片、主视觉按钮与轮播点及搜索卡的相交情况。
- 微信内置 WXML、WXSS 编译检查通过；小程序打包资源检查通过，主包源文件约 1532 KiB，低于检查器的 2048 KiB 限额。
- 小程序控制器、日期和线路列表相关 60 项测试通过；既有筛选布局检查 24 组通过。
- 网页覆盖 320 / 390 / 760 / 1024 / 1440px，检查日间、深色、文字模式和中英文大字号；实际点击验证主视觉入口不自动筛周末、保留已选日期、轮播点可切换图片。
- 网页生产构建通过。全站测试 308 / 310 通过；另两项订单账号隔离用例在未修改的 HEAD 归档中也复现失败，本次没有修改订单模块。
- 小程序图片为实际 WXML 编译树与 WXSS 的浏览器兼容预览，不代表微信真机渲染结果。尚未完成真机验收；本次没有发布线上版本。

预览产物位于本机 `/tmp/bj-home-brand-refresh/`，临时目录可能被系统清理。

## Review 后补充

- 网页点击目的地或热门词时，清除原有玩法标签，并重建线路目录以复位其内部天数、玩法筛选。重复点击同一个目的地同样生效；已选的团期日期保留。
- 网页头图、圆点数量、当前选中项和自动切换使用同一份实际图片列表。后台头图优先，其次兼容旧 gallery，最后使用三张默认风景；只有一张图片时隐藏圆点。
- 删除小程序首页根节点多余的 `overflow:hidden`，图片和卡片仍各自裁切；日期弹层的祖先没有改变 fixed 定位参照的 transform 等属性。微信真机贴底表现仍待验收。
- 小程序头图失败后使用的是远程 HTTPS 风景图，而非包内本地图。远程兜底再次失败时隐藏图片，显示渐变背景；原有线路编号会保留。
- 本轮新增网页首页行为测试 7 项，与线路筛选及展示测试合计 16 项通过，生产构建通过。浏览器实测 2 / 5 / 1 / 0 张后台图及旧 gallery，圆点数量与图像选择一致；先选玩法再搜目的地、重复搜索相同目的地时，请求均不残留玩法或天数。
- 日期弹层专项兼容预览覆盖 320 / 390 / 430px × 日间 / 深色，共 6 组。页面滚到中后部后，遮罩仍覆盖视口、弹层仍贴底，无横向溢出，微信模板与样式编译通过。这些检查不替代微信真机验收。
