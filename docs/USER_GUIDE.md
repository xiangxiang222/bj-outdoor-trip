# 北野行 · 用户端使用文档

适用于 H5 演示站与微信原生小程序。两者打同一套 API，操作路径一致，仅分享调起方式不同。底栏为 **首页 / 官方 / 规则 / 我的**（线路与拼团收在首页里）。

## 1. 入口与演示账号

| 端 | 怎么打开 |
| --- | --- |
| 本地 H5 | 启动后访问 http://127.0.0.1:3781/m （若系统开了 HTTP 代理，请用 `127.0.0.1` 而不是 `localhost`） |
| 线上 H5 | http://192.144.167.212/m |
| 小程序 | 微信开发者工具导入 `miniprogram/`。默认请求线上 API。真机调试 HTTP IP 时关闭「校验合法域名」 |

演示账号（本地执行 `npm run seed` 后；线上演示环境同样可用）：

| 角色 | 手机 | 密码 |
| --- | --- | --- |
| 个人会员 | 13800138000 | 123456 |
| 公司开团 | 13900139000 | 123456 |
| 个人领队 | 13700137000 | 123456 |

登录、注册页使用**图片验证码**（点图片刷新）。短信验证码接口仍保留（演示固定 **888888**），当前登录/注册界面不使用。微信登录为演示授权，不会跳转真实微信开放平台。

## 2. 登录与注册

「我的」页可进入登录。页内切换 **登录 / 注册**：

- **登录**：已注册手机号 + 密码 + 图片验证码
- **注册**：昵称 + 手机号 + 图片验证码 + 不少于 6 位密码

也可点「微信登录」（演示授权）。

登录成功后可改资料：昵称、身份证（自动填生日/籍贯）、公司名称。身份证在展示时脱敏。

未登录时仍可浏览线路。「我的报名 / 收藏 / 会员」入口可见；点进去若未登录会跳到登录页，并在成功后回到原来的页面（不会出现返回键死循环）。

「我的」底部可 **注销账号**：未出行的报名会取消，手机号、密码、微信绑定会清空，同一手机号可以重新注册。旧 token 立即失效。

## 3. 浏览线路

- **首页**是发现页：顶部两张轮播覆盖全部上架景点，点图进入对应线路详情；近 15 日出发明细、按天数/目的地跳进线路目录、看正在拼团、周末一日游精选。已登录且有未出行报名时，顶部显示「即将出行」
- **线路**是完整目录：搜索、天数、类型筛选全部 30 条
- 详情包含封面、相册、亮点、行程、费用、装备清单、须知、常见问题、阶梯价、车型、近期排期、出行评价（姓名脱敏）
- 点击封面或相册可放大查看（H5 灯箱，左右切换 / Esc 关闭；小程序调用 `wx.previewImage`）
- 「收藏」登录后生效，在「我的 → 收藏」查看；小程序线路详情也有收藏入口

预置 30 条线覆盖慕田峪、古北水镇、十渡、野三坡、雾灵山、乌兰布统、承德、北戴河、五台山等。R29 五台山使用五台/云冈实景封面。

## 4. 开团（发布排期）

在线路详情选择「发布排期 / 开团」：

1. 选择出发日期、车型（座位即人数上限）、集合点、成团人数
2. **个人拼团**：自己当领队，好友报名先占座，费用待出行前支付
3. **公司团**：须填写或账号内已有公司名；同事先报名挂账，费用由公司统一支付

发布成功后可分享：

- **H5**：排期页点「分享到微信」，优先调起系统分享；不支持时展示报名二维码并可复制链接（海报接口无需登录）
- **小程序**：排期页 / 线路详情用原生 `open-type="share"` 转发给好友或群
- 短链形式：`/api/share/{token}`，打开后进入该排期

发起人可在排期页 **解散拼团**（必须填写理由）。解散后取消全部报名，已付款的标记退款，并向出行人写入取消短信记录。

## 5. 拼团报名

打开某次排期：

1. 顶部相册可轮播。大巴展示已确认的车型、座位数，确认车牌后显示车号；有车辆照片时可点开查看
2. 集合点可打开地图（已知点定位到坐标；H5 跳转高德，小程序调用系统地图）
3. 预报按目的地景点，默认展示 6–20 点气温曲线（有雨时用浅色柱表示降水）。名单与座位上的姓名可进个人主页（相册、拟出行 / 已参与 / 关注的线路）
4. 报名前点空位提示「早报名早选座」；报名后可在座位图改座。报名成功后展示本团微信群二维码，并可勾选候选团 / 替代团（本团未成团则自动转团，价格多退少补）
5. 领队位显示领队1、领队2（名字+头像可点）；空位可「报名领队」。推荐领队首次带队完成后奖励推荐者 200 元。推荐报名成功按人数结算报名费 5%
6. 待支付为红色，登录后任何人可点「去支付」代付（演示立即成功）。已支付为绿色
7. 官方微信、用户群、本团咨询群在页面底部；「官方」页汇总各平台账号，「规则」页是各线路公共部分
8. 填写**出行人姓名、手机、身份证**（一人一证，同团不可重复；须 18 位且校验码正确）
9. 填写**紧急联系人**（手机不能与出行人相同），勾选健康声明与户外风险告知
10. 会员自动按会员价报价。报名时**不扣积分**；页面提示积分抵现将在付款时使用

排期页同时展示装备清单与退改摘要。

**个人拼团**：提交后即占座，状态为「待支付」，**不调起微信支付**。提示「已报名占座，费用待出行前支付」。

**公司团**：提交后提示「费用由公司统一支付」，无需个人付款。开团公司账号可在排期页执行统一支付；后台也可代结算。

满员仍可加入候补（不占座）。已解散的团无法继续报名。达到成团人数后系统自动匹配导游；拼团列表、首页正在拼团、线路排期和排期详情都可点导游姓名进入简介（擅长线路、近期带团）。未匹配时点「先看看领队」进入导游列表。首页「领队导游」也可进入同一详情。

## 6. 取消报名、订单、评价

- 「我的报名」查看历史订单、支付状态、脱敏证件号。「我的」与首页也会提示最近一次即将出行
- 出发日之前、且拼团未解散时，可点 **取消报名**：名额释放，同一身份证可再报；若已付款则标记退款
- **出发当天及行程开始后**、或团已解散，不能再取消
- 报名成功（非候补、未取消）后可在订单页 **去评价**（1～5 分 + 文字，每人每团一条）。演示环境不强制出行日已过。评价会出现在线路详情和该团排期页，姓名脱敏

支付状态含义：

| 值 | 界面文案 |
| --- | --- |
| `unpaid` | 待支付（已占座） |
| `paid` | 已支付 |
| `company_pending` | 公司挂账 |
| `refunded` | 已退款（取消或解散后） |

## 7. 会员与积分

- 「我的」非会员点 **开通会员** 会立即开通并进入会员中心；已是会员则进入会员中心
- 年费 **99 元**（演示环境直接记成功并开通），有效期 365 天；已是会员则从当前到期日顺延
- 会员价为门市价 **95 折**；开通还赠送 **一次 100 元以内团** 免费名额
- 消费入账：实付 1 元 ≈ 1 积分，会员 ×1.2；开通会员演示赠送 99 积分
- 「我的」可看积分流水

## 8. 本团画像

排期详情点「本团画像」，或统计页展示：

- 男女比例
- 年龄段（由身份证生日计算）
- 籍贯（身份证行政区划）

仅统计未取消的报名。

## 9. 小程序与 H5 差异

| 能力 | H5 | 小程序 |
| --- | --- | --- |
| 微信登录 | 演示按钮 | `wx.login` code 换会话（演示 AppId 仍走 mock） |
| 图片验证码 | 接口返回 data URL，直接显示 | 把 base64 写到本机临时文件再 `image` 展示 |
| 分享 | 二维码 + 复制链接 | 好友 / 群原生转发按钮 |
| 报名支付 | 报名不付款；出行前再付（演示未接真支付） | 同上 |
| 看大图 | 页面灯箱 | `wx.previewImage` |
| 集合点 | 打开高德搜索 | 复制地址后自行搜地图 |

小程序默认请求线上 `http://192.144.167.212`。本地联调时把 `miniprogram/config.js` 里的 `USE_LOCAL_API` 改为 `true`（开发者工具走 `127.0.0.1:3780`，真机走局域网地址）。真机访问 HTTP IP 需关闭合法域名校验。

正式上线：更换小程序 AppId，配置服务器域名，填写真实 `WX_APPID` / 商户号，并关闭 mock。
