# 同行者众 · 用户端使用文档

适用于 H5 演示站与微信原生小程序。两者打同一套 API，操作路径一致，仅分享调起方式不同。底栏为 **首页 / 活动 / 行程 / 我的**：首页是山野拼团，活动是同城局（掼蛋、跑步、电影、招募），行程是待出行和历史报名，客服与规则放在「我的」里。布局说明见 [MOBILE_LAYOUT.md](./MOBILE_LAYOUT.md)。

产品名称 **同行者众**，口号 **在山野，遇见爱**。顶栏是图形标 + 活字，不要把任何学校名称写进品牌。

## 2. 登录与注册

「我的」页可进入登录。页内切换 **登录 / 注册**：

- **登录**：已注册手机号 + 密码 + 图片验证码
- **注册**：昵称 + 手机号 + 图片验证码 + 不少于 6 位密码

也可点「微信登录」（演示授权）。

登录成功后可改资料：昵称、身份证（自动填生日/籍贯）、公司名称。身份证在展示时脱敏。H5 从「我的 → 个人主页」进自己的主页传相册。

未登录时仍可浏览线路。底栏「行程」未登录时显示登录入口；「收藏 / 会员 / 学生认证」从「我的」点进去会跳到登录页，成功后回到原来的页面（不会出现返回键死循环）。

「我的」底部可 **注销账号**：未出行的报名会取消，手机号、密码、微信绑定会清空，同一手机号可以重新注册。旧 token 立即失效。

## 3. 首页（山野发现）

首页状态栏是图形标 +「同行者众」+「在山野，遇见爱」。H5 首页不再显示第二行绿色标题栏。

从上到下：

1. **全幅轮播**：`GET /home` 的 `brand.slides`，点图进入对应线路详情。
2. **学生认证卡**：未认证显示「学生认证」；审核中显示「审核中」；已认证显示学校名。认证后可走学生价（9 折），部分团仅限已认证学生或名单里的高校。
3. **即将出行**：已登录且有未出行报名时出现，点进「行程」Tab。
4. **去哪儿玩**：城市 chips，筛选正在拼的山野团。
5. **哪天玩**：默认收起。展开后可看最近十五天、按月、按节日。
6. **想怎么玩**：玩法标签（后台「玩法标签」维护）。
7. **特价 chips + 发团**：发团提交后需管理员审核，通过后出现在首页。
8. **团卡片**：只列出 `channel=trip` 且仍有余座的团。不含同城局。
9. **页脚**：只留「客服与规则」，会员/抽奖等入口不在首页。

完整 30 条线路目录仍可打开 `/m/routes`（底栏不再单独放「线路」）。预置线路覆盖慕田峪、古北水镇、十渡、野三坡、雾灵山、乌兰布统、承德、北戴河、五台山等。R29 五台山使用五台/云冈实景封面。

详情包含封面、相册、亮点、行程、费用、装备清单、须知、常见问题、阶梯价、车型、近期排期、出行评价（姓名脱敏）。点击封面或相册可放大（H5 灯箱；小程序 `wx.previewImage`）。「收藏」登录后生效，在「我的 → 收藏」查看。

## 4. 活动 Tab（同城局）

主标题「同城局」。顶卡说明「掼蛋、跑步、看电影，户外请走首页」，并提供 **发起一局**。

四宫格分类：掼蛋 / 跑步 / 电影 / 招募。列表左侧是日期块（日 + 周几 + 月），右侧是标题、地点、余位；有封面则右侧小图。免费局标「免费」，不写 ¥0。空态仍可点分类去发布。

种子数据有四场演示局（周五夜掼蛋、朝阳公园夜跑、周末电影、高校跑团招募）。

发布同城局：选玩法、标题、地点、城区、时间、人数上限。不必选大巴。提交后待审，通过后出现在本 Tab。

## 5. 开团（山野）

在线路详情选择「发布排期 / 开团」，或首页点「发团」。发布页可切换「户外线路」与「同城局」。

户外开团：

1. 选择出发日期、车型（座位即人数上限）、集合点、成团人数
2. **个人拼团**：自己当领队，好友报名先占座，费用待出行前支付
3. **公司团**：须填写或账号内已有公司名；同事先报名挂账，费用由公司统一支付
4. 可勾选仅学生、限定高校、组合团等

发布成功后可分享：

- **H5**：排期页点「分享到微信」，优先调起系统分享；不支持时展示报名二维码并可复制链接（海报接口无需登录）
- **小程序**：排期页 / 线路详情用原生 `open-type="share"` 转发给好友或群
- 短链形式：`/api/share/{token}`，打开后进入该排期

发起人可在排期页 **解散拼团**（必须填写理由）。解散后取消全部报名，已付款的标记退款，并向出行人写入取消短信记录。

## 6. 拼团报名

打开某次排期：

### 6.1 同城局

只问三件事：周几几点、在哪、还缺几人。详情页不展示大巴座位图、装备、保险、推荐佣金和本团画像。名单不猜年龄段。

报名只需**称呼 + 手机**；同一账号每局只能报一次。免费局成功提示「已报名，到场即可」。已报名后底部报名按钮消失，改为「已报名，到场找发起人即可」，并可看本局微信群。

满员仍可候补，文案为「本局已满」。出发日前可取消；当天不可取消。

### 6.2 山野团

1. 顶部相册可轮播。大巴展示已确认的车型、座位数，确认车牌后显示车号；有车辆照片时可点开查看
2. 集合点可打开地图（已知点定位到坐标；H5 跳转高德，小程序调用系统地图）
3. 预报按目的地景点，默认展示 6–20 点气温曲线（有雨时用浅色柱表示降水）。名单与座位上的姓名可进个人主页（相册、拟出行 / 已参与 / 关注的线路）
4. 报名前点空位提示「早报名早选座」；报名后可在座位图改座。报名成功后展示本团微信群二维码，并可勾选候选团 / 替代团（本团未成团则自动转团，价格多退少补）
5. 领队位显示领队1、领队2（名字+头像可点）；空位可「报名领队」。推荐领队首次带队完成后奖励推荐者 200 元。推荐报名成功按人数结算报名费 5%
6. 待支付为红色，登录后任何人可点「去支付」代付（演示立即成功）。已支付为绿色
7. 官方微信、用户群、本团咨询群在行程页底部；「我的 → 客服与规则」汇总各平台账号、FAQ 与公共规则（`#rules` 直达规则）
8. 填写**出行人姓名、手机、身份证**（一人一证，同团不可重复；须 18 位且校验码正确）
9. 填写**紧急联系人**（手机不能与出行人相同），勾选健康声明与户外风险告知
10. 可选保险与补给。会员自动按会员价报价。报名时**不扣积分**；页面提示积分抵现将在付款时使用
11. 本团若发行了公开优惠券，排期页可点领取；扫短链 `/c/口令` 或打开 `/m/coupon/口令` 登录后入账，再跳转报名自动带券。后台也可把券发到指定手机/会员并短信带专属短链。「我的」可看优惠券列表。券与会员 95 折取更低，不叠加；保险另计。候补先占用、递补成功才核销；取消或解散会退回未用。
12. 部分团仅限已认证学生，或仅限名单里的高校。学校名能对上（含简称包含）即可；未认证或外校会在报名页看到原因，需先走「学生认证」。开团时可勾选这两项。

排期页同时展示装备清单与退改摘要。满员候补文案为「本车已满」。达到成团人数后系统自动匹配导游；拼团列表和排期详情都可点导游姓名进入简介。未匹配时点「先看看领队」进入导游列表。「我的 → 推荐领队」也可进入同一列表。

**个人拼团**：提交后即占座，状态为「待支付」（有应付金额时），**不调起微信支付**。提示「已报名占座，费用待出行前支付」。

**公司团**：提交后提示「费用由公司统一支付」，无需个人付款。开团公司账号可在排期页执行统一支付；后台也可代结算。

已解散的团无法继续报名。

## 7. 行程 Tab

登录后：

- 顶部 chips：**待出行** / **历史**，带数量
- 待出行第一张做成「下一趟」大卡（集合时间、地点），其余用日期块列表
- 标签区分「同城局」与「山野团」
- 免费局显示「免费」，不显示 ¥0；山野团可带座号
- **取消报名**是卡片上的文字链，不是主按钮
- 点卡片进入该次排期
- 历史里可「去评价」或「完成活动 / 评选」（评价、第二次抽奖、照片评选）

未登录显示登录入口。空态引导去首页或同城局。

出发日之前、且拼团未解散时，可取消：名额释放；若已付款则标记退款。**出发当天及行程开始后**、或团已解散，不能再取消。报名成功（非候补、未取消）后可评价（1～5 分 + 文字，每人每团一条）。演示环境不强制出行日已过。评价会出现在线路详情和该团排期页，姓名脱敏。

支付状态含义：

| 值 | 界面文案 |
| --- | --- |
| `unpaid` | 待支付（已占座） |
| `paid` | 已支付 |
| `company_pending` | 公司挂账 |
| `refunded` | 已退款（取消或解散后） |

## 8. 我的

已登录时顶部是夜色资料卡（昵称、手机、会员标、积分、到期日）。

三组列表，不重复「行程」Tab 的即将出行大卡：

| 组 | 入口 |
| --- | --- |
| 出行 | 个人主页、我的收藏 |
| 权益 | 优惠券、开通会员 / 会员中心、学生认证、团体认证、推荐报名、推荐领队、抽奖 |
| 服务 | 客服与规则、功能建议与找 BUG、去发团 / 发起一局 |

小程序「我的」目前权益组只有优惠券、会员、抽奖；学生认证请从首页卡片进入（已登录会跳到「我的」，独立认证页尚未做）。H5 有完整学生/团体页。

### 8.1 会员与积分

- 非会员点 **开通会员** 会立即开通并进入会员中心；已是会员则进入会员中心
- 年费 **99 元**（演示环境直接记成功并开通），有效期 365 天；已是会员则从当前到期日顺延
- 会员价为门市价 **95 折**；开通还赠送 **一次 100 元以内团** 免费名额
- 学生价为门市价 **9 折**（须认证通过）
- 消费入账：实付 1 元 ≈ 1 积分，会员 ×1.2；开通会员演示赠送 99 积分
- 会员中心可看积分流水

### 8.2 学生认证（H5 `/m/student`）

填写**学校全称**后提交，状态变为审核中。后台「用户与会员」点「过学生」后生效。认证学校需与开团填写的高校名单对得上（包含匹配）。不要在界面上预设具体校名按钮。

### 8.3 抽奖与完成活动

报名前可在「抽奖」抽一次。出行后在行程历史或排期页点「完成活动」，可评价、抽第二次、参加照片评选。两次奖品一致且不是谢谢参与，即可翻倍领取。

### 8.4 客服与规则

「我的」或首页页脚进入。主操作是复制官方微信 / 用户群名。快捷入口：意见反馈、报名前抽奖、学生认证（H5）、平台规则。关注我们、FAQ 手风琴、规则默认收起；`#rules` 进入时展开并滚到规则。

## 9. 本团画像

仅山野团：排期详情点「本团画像」，或统计页展示男女比例、年龄段、籍贯。仅统计未取消的报名。同城局不展示此入口。

## 10. 小程序与 H5 差异

| 能力 | H5 | 小程序 |
| --- | --- | --- |
| 微信登录 | 演示按钮 | `wx.login` code 换会话（演示 AppId 仍走 mock） |
| 图片验证码 | 接口返回 data URL，直接显示 | 把 base64 写到本机临时文件再 `image` 展示 |
| 分享 | 二维码 + 复制链接 | 好友 / 群原生转发按钮 |
| 报名支付 | 报名不付款；出行前再付（演示未接真支付） | 同上 |
| 看大图 | 页面灯箱 | `wx.previewImage` |
| 集合点 | 打开高德搜索 | 复制地址后自行搜地图 |
| 学生 / 团体认证 | `/m/student`、`/m/group` | 尚无独立页；首页学生按钮跳「我的」 |
| 图形标 | SVG `BrandMark` | `images/mark.png`（官方页） |

小程序默认请求线上 `http://192.144.167.212`。本地联调时把 `miniprogram/config.js` 里的 `USE_LOCAL_API` 改为 `true`（开发者工具走 `127.0.0.1:3780`，真机走局域网地址）。真机访问 HTTP IP 需关闭合法域名校验。

正式上线：更换小程序 AppId，配置服务器域名，填写真实 `WX_APPID` / 商户号，并关闭 mock。
