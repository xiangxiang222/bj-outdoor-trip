# 同行者众 · 北京周边短途游

第一阶段可运行原型。口号 **在山野，遇见爱**。两条供给：

- **山野团**：覆盖北京周边 **1 / 2 / 3 / 5 日** 短途线路（预置 **30 条**）、线路图文详情、多日期排期、公司团 / 个人拼团、实名报名占座
- **同城局**：掼蛋 / 跑步 / 电影 / 招募，姓名+手机即可报名

另有会员与积分、学生认证与学生价、后台统计与成团后自动匹配导游。

## 怎么跑起来

需要 Node.js 18+（建议 20）。在项目根目录：

```bash
npm install
npm install --prefix server
npm install --prefix web
npm run seed
npm run dev
```

部署发生在 GitHub Actions 上，**不需要 iPhone 能 SSH**。**合并到 `main`**（或直接推 `main`）会自动上线；功能分支不会部署。也可在 Actions 里手动 Run workflow，或在能登录服务器的电脑上执行 `./scripts/deploy.sh`（同步到腾讯云、构建、PM2 进程名 `beiyexing`，目录 `/var/www/beiyexing`）。

第一次需要在仓库 **Settings → Secrets and variables → Actions** 配置 Secret `DEPLOY_SSH_KEY`（服务器 **`ubuntu`** 用户私钥全文）。不要配成 Deploy keys，也不要用 `root`。**只用手机也可以配完**，步骤见 [docs/DEPLOY.md](docs/DEPLOY.md)。**不要**在生产库执行 `npm run seed`（会清空业务数据）。部署脚本仅在目标机还没有数据库文件时才会 seed。

## 30 条线路从哪来

线路整理自北京周边跟团/户外常见目的地（慕田峪、古北水镇、十渡、野三坡、雾灵山、乌兰布统、木兰围场、承德、北戴河、五台山等），每条包含：

- 封面图（本地 SVG 主题图；若联网成功还会下载实景照片到 `server/public/static/photos`）
- 相册、亮点、逐段行程、费用含/不含、装备与注意事项
- 人数阶梯价（10 / 20 / 30 / 50 人）和会员价
- 可选车型（10 人考斯特、15 座商务、30/38/50 座大巴）
- 集合点（东直门、西直门、国贸、丽泽）

首页按城市 / 玩法 / 折叠日历筛选**正在拼的山野团**；完整目录仍可打开 `/m/routes`。种子另有 4 场演示同城局（掼蛋、夜跑、电影、招募）。

## 第一阶段功能

**用户侧**

- 底栏：首页（山野）/ 活动（同城局）/ 行程 / 我的
- 微信登录（小程序 `wx.login`；H5 为演示授权）
- 手机号注册 / 登录：图片验证码 + 密码
- 线路列表与详情（图文、行程、阶梯价、车型）
- 一条线路多个出发日期；用户或公司可「发布排期」/「发团」（须后台审核）
- 同城局轻报名：姓名+手机，按账号去重；已报名隐藏报名按钮
- 个人拼团：报名占座，费用待出行前支付；公司团先上车后统一支付
- 最低成团人数、车型座位上限
- 取消报名（出发日前）；发起人解散拼团（必填理由，已付款标记退款）
- 分享到微信（小程序原生转发；H5 报名二维码 + 复制链接）
- 开通会员（演示立即生效）、会员价 95 折、学生价 9 折、积分规则
- 报名后查看本团画像（男女、年龄段、籍贯；仅山野团）
- 成团后按线路类型自动匹配导游；可点进导游个人页看简介与近期带团
- 满员候补、2+2 座位图、出行保险加购、目的地天气
- 山野团报名须紧急联系人、健康声明与户外风险确认；成团后显示铁定出发
- 装备清单、行前常见问题、折叠出发日历、即将出行进行程 Tab
- 报名成功后评价；完成活动后第二次抽奖与评选
- 注销账号（软删除，同一手机可再注册）
- 导游工作台 `/g`：行程、名单、签到、锁座调座

**管理后台**

- 线路增删改（下架）、上传封面/相册、发布排期、审核用户发团
- 每条线路人数与收入汇总
- 每次活动填写大巴/门票/住宿/餐食/导游等成本，自动算利润
- 公司团一键结算
- 解散单团或全部拼团
- 报名筛选与代取消
- 用户搜索、开通/取消会员、调整积分、审核学生/团体、注销
- 玩法标签
- 管理员账号（增删改、停用、重置密码；运营角色不可见）
- 报名明细、用户与会员列表、本团画像图表

## 微信小程序

原生小程序在 `miniprogram/`。用微信开发者工具打开该目录：

1. 默认请求线上 `http://192.144.167.212`。本地联调把 `miniprogram/config.js` 的 `USE_LOCAL_API` 改为 `true`
2. 详情里关闭「校验合法域名、web-view、TLS」，以便真机请求 HTTP IP
3. 正式上线需换成真实 AppId，并在 `server/src/config.js` 填写 `WX_APPID` / `WX_APPSECRET` / 商户号

H5 用户端与小程序打同一套 API。H5 有独立学生/团体认证页；小程序首页「学生认证」在已登录时跳到「我的」，独立页尚未做。

## 支付说明

默认 `wechat.mock = true`。个人拼团报名**不调起支付**（`needPay: false`）。开通会员在演示环境直接记成功。公司团由开团人或后台结算。接入真微信支付时：

- 配置商户号与回调 `WX_PAY_NOTIFY`
- 小程序里把 `wx.requestPayment` 换成真实 `timeStamp/nonceStr/package/paySign`
- 设置 `WX_PAY_MOCK=0`

取消报名、解散拼团会对已付款座位做退款标记，尚未对接微信原路退款。
