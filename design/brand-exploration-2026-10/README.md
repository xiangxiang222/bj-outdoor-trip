# 同行者众 · 标志设计探索

四个独立候选方向，适用小程序、H5、活动海报、跑步服、社团服装。保持紫红的品牌缘起，不将图形限定为山峰或徒步人，也不使用学校校徽与校名元素。

打开 `index.html` 可切换双色、纯色、反白并下载各稿。当前仅创建设计提案，未替换生产资源。

| 编号 | 名称 | 构成 | 取舍 |
| --- | --- | --- | --- |
| A | 并肩 | 一高一低的双折带，两条并行向前的路径 | 运动感强；字母感比中文识别强，适合作为运动候选 |
| B | 同印 | 简化几何「同」，紫色主体与红色结构接点 | 推荐长期主标方向；中文名称对应直接，方形适合头像 |
| C | 共席 | 四个圆角模块向中心聚合，四边留出入口 | 更亲近与包容；抽象度较高，需要品牌持续使用建立关联 |
| D | 同路 | 两条开口轨道相接，留出透明分隔 | 更流动，适合纹样；需注意与通用连接符号的差异 |

- `png/`：对应 PNG。图形宽 2048 px、横版宽 3040 px、竖版宽 1800 px、图标宽 1024 px。除应用图标外，独立标志 PNG 背景透明。
- `tongxing-logo-concepts.zip`：整套可下载文件。
- `source/build.py`：直接矢量绘制与导出源文件。

## 配色与制作

品牌紫 `#5B3B8C`；伴色红 `#BD4055`；深墨 `#282331`。红色用作相遇的伴色，单色版本保持完整构图。以上为屏幕 RGB 参考，实际服装按面料、工艺先打样确定专色。刺绣的最小尺寸需要供应商按线宽与面料验证，24 像素屏幕检验不能替代实物打样。

图形为直接设计的 SVG 路径，未调用图像生成模型或付费图像 API。中文展示字标以本机 Hiragino Sans GB W6、说明以 W3 为基础，英文以 Avenir Next 为基础，导出为路径，不打包字体文件。当前字标用于方向展示；选定方向后可继续定制中文四字的细节。英文应用文案仅为示例，没有替换产品现有名称或口号。

复现需要 Python `fonttools`、`rsvg-convert` 与源文件所列的本机字体路径。图稿可直接在支持 SVG 的设计工具中继续编辑。

当前是设计候选，未做商标近似检索；正式定稿时再确认图形近似与最终字标的商用授权。
